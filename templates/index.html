What should a diet file look like?

A plain-text table with two columns: the exchange reaction id (or the metabolite id) and a flux value. CSV, TSV or semicolon-separated all work, and a header row is optional (it is detected and skipped).

  • A positive number is the maximum uptake rate (mmol/gDW/h) for that nutrient.
  • Every exchange not listed is closed for uptake, so list everything the cells may consume.
  • Ids may be exchange reactions (EX_glc__D_e) or metabolites (glc__D, glc__D[e]). Unmatched rows are reported after the analysis.

Analyze multiple models

This can take a long time. Every model is loaded and analysed on its own (growth, flux variability for blocked reactions, exchange essentiality, annotation checks). Genome-scale models can take several minutes each, so a batch of many models may run for a long while. Keep this tab open until it finishes, and start with two or three models if you are unsure.

Compare several models side by side: growth, size, namespaces, blocked reactions, essential exchanges and more, with automatic quality findings. Get the comparison as an Excel workbook and an HTML report.
